# Протокол проверки доработки от 9 ноября 2026 года

Браузер: Chromium 151.0.7922.34. Локальная среда macOS, программный WebGL. Дата и время выполнения отдельных сценариев записаны в JSON в UTC.

## Результаты

- 14 основных проверок — PASS: движение, прыжок и приземление, пауза (включая мировое время), закрытый выход, разрушение стены рывком, контрольная точка, сохранение и восстановление прогресса, два переключателя, потеря каждой единицы здоровья и возрождение, переходы между уровнями, финал, повторная игра, отсутствие JavaScript-исключений. Файл results.json.
- 5 дополнительных проверок — PASS: стена блокирует ходьбу без рывка; движущаяся платформа переносит героя; пауза сохраняет положение платформы и фазу ловушки; активная ловушка наносит урон при столкновении; запуск через file:// без сети создаёт видимую сцену с активным WebGL2-контекстом без исключений. Файл additional-results.json.
- Все три уровня пройдены сквозным клавиатурным сценарием без телепортации, изменения состояния героя или пропуска уровней. Число возвратов в конце маршрута: 0. Файл keyboard-route.json, новое видео screenshots/keyboard-playthrough.webm в локальном архиве.
- Основные тесты заново сняли меню, три сцены, финал и интерфейс 390×844. Снимки из текущего запуска находятся в локальном архиве. Снимки и видео исходного публичного релиза 1.0.0 относятся к 21 октября и не являются доказательством нового запуска.

## Метод и ограничения

Основные и дополнительные тесты отдельных механик используют диагностическое позиционирование. Сквозной сценарий использует диагностический интерфейс только для чтения состояния. Это автоматизированные испытания, а не пользовательское тестирование. Производительность на целевом компьютере, физические мобильные устройства и независимая оценка удобства и баланса не проверены.

## Повторение

Для игры достаточно открыть index.html из распакованного архива. Для тестов нужны Node.js, Playwright и установленный Chromium. В корне проекта запустить локальный сервер на порту 8765, затем выполнить:

```sh
node tests/automated-checks.cjs
node tests/additional-checks.cjs
node tests/keyboard-route.cjs
```

Тесты используют локальный адрес 127.0.0.1:8765. Диагностический интерфейс доступен только при #test. Все сценарии сохраняют результаты в tests/. Клавиатурный маршрут записывает видео, поэтому выполняется заметно дольше компонентных проверок.
