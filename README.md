# Носорог — Возвращение энергии

Самостоятельный учебный 3D-платформер для преддипломной практики в Университете «Синергия». Это новый проект с собственным персонажем, а не продолжение отсутствующих исходников прошлых семестров. Учебный проект не является официальным продуктом университета.

## Запуск

1. Полностью распакуйте архив.
2. Откройте `index.html` двойным щелчком в современном браузере с WebGL.
3. Нажмите «Начать путешествие». Интернет и установка зависимостей для игры не нужны: Three.js входит в архив.

Если браузер ограничивает открытие локальных файлов, запустите в папке проекта `python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Для этого варианта нужен Python 3. Автоматические проверки выполнены через локальный сервер; открытие двойным щелчком проверяется отдельно в протоколе.

## Управление

| Действие | Клавиши |
|---|---|
| Движение по миру | WASD или стрелки |
| Прыжок | Пробел |
| Силовой рывок | Shift, повтор через 0,9 с |
| Включить узел / выход | E, когда появляется подсказка |
| Пауза | Esc |
| Звук | Кнопка справа сверху |

На сенсорных устройствах предусмотрены экранные кнопки. Проверка на физических телефонах не проводилась. Управление привязано к физическим клавишам и работает при русской раскладке.

## Персонаж и механики

Носорог собран из трехмерных примитивов: тело, голова, морда, рог, уши, глаза, руки, ноги и шарф. Движение сопровождается процедурной анимацией. Отдельные модели, текстуры и платные ассеты не нужны. Три единицы здоровья; после падения или потери здоровья герой возвращается к последней контрольной точке. Рывок разрушает коричневые преграды и обезвреживает охранников. Оранжевые ловушки включаются циклически: дождитесь спокойной фазы или перепрыгните их.

Прогресс хранится в localStorage браузера. Сохраняются уровень, активированные цели, контрольная точка, разрушенные преграды, собранные бонусы и счетчики. После перезагрузки нажмите «Продолжить сохранение». Повторное начало уровня сбрасывает его прогресс. Хранилища `file://` и локального сервера могут отличаться. В приватном режиме сохранение может быть недоступно.

## Уровни

1. **Учебный двор.** Пройдите разрывы между островами прыжком. Достигните голубой контрольной точки, разрушьте поперечную коричневую преграду рывком, найдите оранжевый элемент питания и вернитесь к зеленому выходу в дальнем конце острова. Один патруль и два необязательных бонуса.
2. **Промышленный переход.** На большой развилке активируйте два переключателя на левом и правом островах в любом порядке. Слева — движущаяся платформа, справа — циклическая ловушка над разрывом. Разрывы можно перепрыгнуть. После обоих узлов найдите выход на дальнем острове. Охранники и бонусы необязательны для цели.
3. **Энергетическое ядро.** От центрального острова доступны два боковых ответвления: слева силовая преграда, справа ловушка. Третий узел расположен на дальнем острове через разрыв. Включите все три узла и взаимодействуйте с зеленым генератором. Финал подводит результаты прохождения.

Схемы сверху находятся в папке `maps`. На них координаты, поверхности, противники, преграды, ловушки, цели, бонусы и контрольные точки соответствуют данным игры. Это схемы реализации; естественные маршруты и удобство навигации еще требуют оценки игроками.

## Состав проекта

- `index.html` — запуск и интерфейс.
- `style.css` — оформление и адаптивные элементы управления.
- `game.js` — сцена, персонаж, три уровня, физика, столкновения, сохранение, звук и игровая логика.
- `vendor/three.min.js` — Three.js 0.160.0, лицензия MIT в `vendor/THREE-LICENSE.txt`.
- `maps/` — схемы уровней в SVG.
- `screenshots/` — фактические изображения работающей игры.
- `tests/` — выполненные автоматические проверки и протокол с ограничениями.

## Ограничения

Это учебный прототип: упрощенная физика без отдельного физического движка, фиксированный ракурс камеры, геометрические модели, синтезированные звуковые сигналы. Пользовательские испытания, измерения на согласованном целевом компьютере и подтверждение руководителя практики не выполнены. Целевые 60 кадров/с из проектного ответа не заявляются как достигнутые. Дополнительные короткие проходы и сложные сюжетные сцены из первоначальной концепции в эту версию не включены.
